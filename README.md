# TabTreeNote

ローカルのテキストメモを「タブ × ツリー構造」で階層管理する、個人用のメモエディタです（Electron + TypeScript、Windows 11 向け）。

フリーソフト「CatMemoNote」（作者 Pyo / PapparaSoft）の思想 ── タブ＝フォルダ、メモ＝テキストファイル、3ペイン構成、ドラッグ＆ドロップ操作、レジストリに依存しないポータブル運用 ── を参考にした**独自実装**です。CatMemoNote のコードや素材は含んでいません。

## 主な機能

- **タブ管理** — 1タブ＝1フォルダ。作成・リネーム・削除（ごみ箱送り）、ドラッグでの並べ替え、既存フォルダのドラッグ登録
- **ツリー管理（左ペイン）** — メモの親子階層化、開閉、ドラッグ＆ドロップでの並べ替え・階層変更・タブ間移動、複数選択、色ラベル
- **テキスト編集（右ペイン）** — CodeMirror 6 ベースのエディタ、UTF-8 / Shift_JIS の読み込み、改行コードの保持、自動保存、チェックリスト、ライト／ダークテーマ
- **Markdown** — `.md` メモのライブプレビュー、装飾ツールバー
- **検索・置換** — メモ内の検索・置換（正規表現対応）、全メモ横断の全文検索
- **リンク** — URL / mailto / ファイルパス / `memo:タブ名/メモ名` 形式のメモ間リンク
- **暗号化** — メモ単位のパスワード暗号化（AES-256-GCM + scrypt、拡張子 `.txtenc`）、ノード（サブツリー）単位のパスワードロック
- **ファイル監視** — 外部エディタなどによる変更を自動で反映し、競合時は解決ダイアログを表示
- **その他** — タスクトレイ常駐、最前面固定、設定画面、ショートカットのカスタマイズ

## データの保存形式

- メモは**プレーンテキストファイル**（`.txt` / `.md` / 暗号化メモは `.txtenc`）として、タブに対応するフォルダへそのまま保存されます。
- ツリー構造などのメタ情報だけを、タブ単位の JSON に分けて保存します。メタ情報が壊れても本文は失われません。
- フォルダごとコピーすればバックアップできます。外部サービスとの通信はなく、すべてローカルで完結します。

## 動作環境

- Windows 11（主な対象。他の OS は未検証）
- 開発には Node.js と npm が必要です

## 開発・起動方法

```sh
npm install
npm run dev        # 開発モードで起動（Windows では dev.bat でも可）
npm run typecheck  # 型チェック
npm run dist       # ポータブル版 exe をビルド（release/ に出力）
```

> 環境変数 `ELECTRON_RUN_AS_NODE` が設定されていると Electron が起動しません。`dev.bat` はこれを自動で解除します。
